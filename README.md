# Olsint
**Olsint** — учебный проект на Python, предназначенный для изучения работы с OSINT.
⚠️ **Важно:** Код предназначен исключительно для образовательных целей. Использование его для преследования **запрещено** и может нарушать законодательство.
## О проекте
Olsint демонстрирует:
*   Поиск данных из открытых источников
## Установка и запуск
### Для Linux
1.  **Установите Python 3 и pip:**
    ```bash
    sudo apt update
    sudo apt install python3 python3-pip git
    ```
2.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/zloy-enot618/ostool-password_in_code/
    ```
3.  **Перейдите в папку проекта:**
    ```bash
    cd ostool-password_in_code
    ```
4.  **Установите зависимости:**
    ```bash
    pip3 install -r requirements.txt
    ```
    или (если возникает ошибка):
    ```bash
    python3 -m pip install -r requirements.txt
    ```
5.  **Запустите скрипт:**
    ```bash
    python3 Olsint.py
    ```

### Для Windows
1.  **Установите Python:**
    *   Скачайте установщик с [официального сайта](https://www.python.org/).
    *   При установке отметьте галочку **«Add Python to PATH»**.
    *   Убедитесь, что установлена версия Python 3.8+.
2.  **Установите Git:**
    *   Скачайте Git с [официального сайта](https://git-scm.com/).
    *   Запустите установщик и следуйте инструкциям.
3.  **Откройте командную строку** (нажмите `Win + R`, введите `cmd` и нажмите `Enter`).
4.  **Клонируйте репозиторий:**
    ```cmd
    git clone https://github.com/zloy-enot618/ostool-password_in_code/
    ```
5.  **Перейдите в папку проекта:**
    ```cmd
    cd ostool-password_in_code
    ```
6.  **Установите зависимости:**
    ```cmd
    pip install -r requirements.txt
    ```
7.  **Запустите скрипт:**
    ```cmd
    python Olsint.py
    ```
