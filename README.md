# OSINT Tool for VK (Olsint)

**Olsint** — учебный инструмент на Python для изучения методов OSINT (разведки по открытым источникам) с фокусом на поиск информации по VK ID. Проект демонстрирует работу с HTTP‑запросами, парсингом веб‑страниц и интерактивным взаимодействием с пользователем.

⚠️ **Важно:** Код предназначен исключительно для образовательных целей. Сбор персональных данных без согласия субъекта может нарушать законодательство (в т. ч. 152‑ФЗ РФ, GDPR). Используйте инструмент только на данных, к которым у вас есть законный доступ.

## О проекте

**Olsint** позволяет:
* искать профиль пользователя VK по его ID или короткому имени;
* находить упоминания VK ID в других социальных сетях (Telegram, Instagram, Twitter/X);
* собирать общие упоминания идентификатора в интернете через поиск Google;
* структурировать найденные данные в удобном для анализа виде.

Проект демонстрирует:
* отправку HTTP‑запросов к поисковым системам с помощью библиотеки `requests`;
* парсинг HTML‑страниц с использованием `BeautifulSoup4`;
* интерактивное взаимодействие с пользователем (ввод пароля, ID, вывод результатов);
* обработку ошибок и таймаутов;
* форматирование вывода в терминале.
